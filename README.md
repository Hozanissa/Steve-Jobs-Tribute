# Steve Jobs Tribute

A static, six-page tribute website about Steve Jobs. It introduces his life and career, summarizes key milestones and achievements, and includes a photo gallery, a rotating quote display, and a contact form. The pages share a sidebar navigation, responsive styling, and a footer.

## View the site

No build tools or package installation are required. Open `index.html` in a browser, or serve the project directory with any static web server and visit the local address it provides.

The contact form submits to Formspree and requires an internet connection. The site also loads the Inter font from Google Fonts when a connection is available.

## Project files

### Pages

- `index.html` — Home page with an introduction to Steve Jobs, a hero image, and links to related pages.
- `biography.html` — A timeline of major life events and a table of career milestones.
- `achievements.html` — Highlights major achievements, including Apple products, NeXT, and Pixar.
- `gallery.html` — Displays the project photographs and product images in a responsive grid.
- `quotes.html` — Shows a randomly selected Steve Jobs quote and a button to display another.
- `contact.html` — Provides a contact form for submitting a name, email address, and message.

### Styles and scripts

- `css/styles.css` — Shared layout, navigation, typography, page-specific styles, gallery grid, and small-screen responsive rules.
- `scripts/script.js` — Selects and displays random quotes, opens gallery images in a new tab when clicked, and handles the contact form's submission message.
